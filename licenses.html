Geographic data

Source data behind the maps

Natural Earth — naturalearthdata.com, obtained from the natural-earth-vector repository. Natural Earth is in the public domain: no permission is needed and no attribution is required. This credit is voluntary.

What that data is used for, precisely: the real-world outlines it provides — administrative boundaries and coastlines — are the raw material our own tools work from. The provinces you play are not those units. They are made for Realmfront: our pipeline merges, splits, simplifies and reshapes the source outlines until each province is large enough to tap on a phone and the map plays the way a chapter needs, and in several chapters the provinces are grouped by hand rather than by any rule. The result is what ships; the source files stay outside the app.

Province names in the twelve world chapters are taken from Natural Earth, which carries each name in the languages the game supports. The names in the European chapters are ours, because those provinces are groupings that no data file knows.

Tools used to make the game

The maps were prepared with the Python libraries Shapely, NumPy, SciPy and Pillow, all open source. They run on a desktop machine while the map data and sprite sheets are being prepared. None of them is part of the app: no code from these libraries is shipped in the Android package, and they are named here only because the maps could not have been built without them.
